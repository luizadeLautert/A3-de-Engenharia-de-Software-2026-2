# A3-de-Engenharia-de-Software-2026-2
Trabalho de faculdade da UC Engenharia de Software.
Para os objetivos do projeto foi estabelecido um aplicativo fantasia chamado BairroDelivery, com o objetivo de realizar entregas dentro de uma região especifica de 5 km do consumidor.

## Organização do Projeto

1. Visão Geral do Projeto
2. Requisitos e Product Backlog
3. Modelagem e Arquitetura de Software
4. Planejamento Ágil e Sprints
5. Gerência de Configuração e Ferramentas
6. Execução, Revisão e Encerramento
7. Referências Bibliográficas

A metodologia escolhida é o Scrum como modelo ágil.
