# 1.5 TERMO DE ABERTURA DO PROJETO (TAP)

| **Elemento** | **Definição** |
| --- | --- |
| Produto | BairroDelivery — plataforma regional móvel e web. |
| Justificativa | Valorizar restaurantes locais por meio de taxas reduzidas e logística regional. |
| Objetivo | Entregar uma solução de pedidos, Pix, conciliação, rastreamento e acessibilidade. |
| Escopo inicial | Cadastro, cardápio, pedidos, pagamentos, entregas, administração e indicadores. |
| Fora do escopo inicial | Operação fora de 5 km, pedidos de múltiplos restaurantes em uma única transação e expansão nacional. |
| Restrições | Raio de 5 km; LGPD; acessibilidade WCAG 2.2 AA; integração com provedor Pix. |
| Premissas | Restaurantes e entregadores aprovados; disponibilidade de serviço de mapas e provedor de pagamentos; estimativas sujeitas a validação. |
| Responsáveis | Jasnah (PO), Dalinar (Scrum Master), Doug (Developers). |
| Critérios de sucesso | Fluxo de pedido completo, Pix e reembolso validados; rastreamento e acessibilidade testados; meta operacional de média &lt; 35 min em acompanhamento. |
| Aprovação | Product Owner: aprovação pendente; orçamento e capacidade ainda a validar. |
